# No Secrets in 3AK-QuantRAG

**CRITICAL RULE:**
The `3AK-QuantRAG` repository is an open-source, public repository.
**NEVER** commit, store, or inject any real API keys, credentials, or secrets into this repository (including config files like `config.yaml`).

All real secrets and API keys must **only** be stored in the internal `TradeSetup` repository (e.g., in `finchat/config/settings.yaml`). For `3AK-QuantRAG`, strictly use placeholder values (e.g., `YOUR_API_KEY`).
